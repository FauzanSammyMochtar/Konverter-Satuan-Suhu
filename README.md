# Konverter Satuan Suhu 

## Deskripsi
Cukup input suhu Celsius yang ingin anda ubah jadi Fahrenheit dan Kelvin.

## Persyaratan
* C Compiler (Seperti GCC/Clang)

## Cara menggunakan
1. Unduh atau clone repositori ini:
git clone https://github.com/FauzanSammyMochtar/Konverter-Satuan-Suhu.git

2. Masuk ke folder proyek:
cd Konverter-Satuan-Suhu

3. Compile program:
clang konverter_satuan_suhu.c -o konverter_satuan_suhu

4. Jalankan program:
./konverter_satuan_suhu
